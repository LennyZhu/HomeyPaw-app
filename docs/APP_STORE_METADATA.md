- Account data is linked to the user and used for app functionality.
- User content includes pet data, photos, journal entries, shared-family content, care logs, and reminders.
- No advertising, tracking, analytics SaaS, precise location, contacts, camera, or microphone.
- Local notifications are optional and used only for care reminders.
- Account deletion is available in the app.
